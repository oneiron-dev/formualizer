## Summary

Converts text to uppercase.

## Remarks
 - Letters of every script are uppercased, one character for one, so the text keeps its
   length: `UPPER("ÿ")` is "Ÿ" and "ß", which has no single-letter capital, stays "ß".
 - Numbers and booleans are first converted to text.
 - Errors are propagated unchanged.

## FAQ

### Is uppercasing fully Unicode-aware?
Yes, with Unicode's one-to-one mapping, as Excel does: accented and non-Latin letters are uppercased, and a letter whose capital takes two letters, such as ß, is left as it is.
